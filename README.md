## Featured Projects

| Project                                                       | Description                                                                                                                                                                  |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [**OmniLogger**](https://github.com/Zeid-M/omni_logger)       | Pre-configured Python logger that captures log messages, `print` statements and uncaught exceptions, with JSON file logs, filters, and alert forwarding.                     |
| [**ChronoCourier**](https://github.com/Zeid-M/chrono_courier) | Priority-based notification service that receives alerts and reports over HTTP and delivers them to Telegram and email, with retry queues and runtime config reload.         |
| [**Telexporter**](https://github.com/Zeid-M/telexporter)      | Real-time IMAP IDLE email watcher that forwards new-mail notifications to Telegram forum topics, with heartbeats and deduplication. Available on PyPI and as a Docker image. |

All three are Python projects built around the same idea: reliable, low-friction monitoring and alerting. OmniLogger can forward warnings and errors to ChronoCourier, which delivers them to Telegram and email.
